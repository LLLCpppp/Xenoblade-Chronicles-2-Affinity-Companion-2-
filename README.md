# 异度神剑2 牵绊圆环助手

[English](README.en.md) · [日本語](README.ja.md)

一个可离线使用的《异度神剑2》牵绊圆环进度与精英讨伐工具。选择异刃立绘，在可视化圆环上录入进度，查看当前还能通过佣兵团推进哪些节点，以及尚未完成的精英讨伐。

推荐 GitHub 仓库名：**`xc2-affinity-companion`**。

| 语言 | 项目展示名称 | 可选仓库名 |
| --- | --- | --- |
| 中文 | 异度神剑2 牵绊圆环助手 | `xb2-qianban-assistant` |
| 日本語 | ゼノブレイド2 キズナリング助手 | `xenoblade2-kizuna-assistant` |
| English | Xenoblade Chronicles 2 Affinity Companion | `xc2-affinity-companion` |

- 雷鼓的4个雷电控制特训节点和萤的3个偷心节点固定为手动推进；其余30个普通交谈节点可佣兵推进，两者均优先于旧打标。

## 开始使用

下载并解压项目，直接用现代浏览器打开根目录的 **`index.html`**。无需安装依赖、构建或登录账号。

也可以在项目目录启动静态服务器：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

然后访问 [http://127.0.0.1:8000](http://127.0.0.1:8000)。若未安装 Python，直接打开 HTML 即可。

- 普通交谈计数条件已按玩家确认恢复为佣兵可推进，并覆盖旧打标；观看牵绊对话、指定剧情人物或任务等独立要求保留原判定。
- 当前阶段受阻时，下一阶段条件非信赖度则提示“需要手动推进”；信赖度条件保留原提示，不改动阶段条件原文或佣兵判定。

## 功能

- 中文、英语、日语切换，自动记住语言；支持三种语言的异刃、精英、节点与地区搜索。
- 立绘选择栏默认展开，添加后保持展开；按未录入、待确认、已确认排序，待确认为琥珀色、已确认为绿色；点击卡片自动定位圆环。支持五阶段可视化圆环、分支进度录入、撤销上次操作。
- **一键点亮全部**：将当前异刃的五阶段和全部技能节点记为完成，同步讨伐状态，可撤销。只修改当前异刃的本地记录。
- 佣兵团判断只考虑每条分支的直接下一节点，不跳过手动前置；不需要选择周目。
- 可派遣卡片显示“佣兵团可开 N（信赖度 M）”，信赖度是其中的技能节点子集，不含阶段解锁；不增加排序选项：仅累计已开放阶段内连续可由普通佣兵任务推进的技能节点，遇手动、需核实或指定任务条件停止，不包含阶段锁，也不代表一趟任务完成。
- 按已开节点数或完成比例排序，卡片平铺换行并显示当前排名；阶段锁不计入节点数量。支持重叠的进度分类。
- “我的未完成讨伐”与“全部角色的讨伐条件”切换，展示共享同一精英的其他异刃、前置状态和圆环跳转。
- 宫比罗与觉醒形态互斥录入；可以移除后重新选择。
- 进度、讨伐勾选和个人规则在当前浏览器保存，可导出、合并导入 JSON。
- **一键重置所有异刃**：经警告确认后清空所有角色录入、圆环进度、讨伐勾选、形态备份和撤销记录，恢复为未录入；个人打标规则保留。请按需先导出备份。

## 数据与译名

Wiki 快照日期：**2026-11-08**。当前包含 55 个可录入圆环的异刃、493 条技能分支、2,188 个技能节点及 220 条阶段条件。讨伐表包含 30 位异刃的 82 个节点，涉及 50 个已确认精英名称、3 个待定敌人名称及 3 条未指定敌人名称的条件。

条件、图片和原文链接来自 [乐园数据管理室](https://xenoblade2.cn/异刃)，佣兵规则依据 [佣兵团任务页面](https://xenoblade2.cn/佣兵团任务)。原始数据保留中文，语言切换只改变显示，不改动存档标识、Wiki 链接或判定规则。

译名按以下顺序处理：

1. 优先使用中文 Wiki 的“英文名 / 日文名”。
2. 参考其他语言 Wiki；可对应的游戏文本使用 [Xenoblade Data](https://xenoblade.github.io/) 中同一数据表、同一编号的中英日条目。
3. 未找到对应名称时采用项目翻译，不标作官方译名。部分条件说明采用模板翻译；有歧义时以中文 Wiki 原文为准。

圆环详情提供可展开的中文原文。`locales.json` 包含译文、专名来源及同编号文本的来源记录；`ATTRIBUTION.md` 说明来源。独立复核报告、CSV 和原始统计下载保留中文。

## 存档与个人规则

玩家记录可保存在关联的本地 JSON 文件中，浏览器同时保留缓存，没有上传接口。切换语言沿用同一份存档。换浏览器、从本地文件转到 GitHub Pages、换域名或改变本地文件位置时，请先导出进度，再到新地址导入。

个人打标规则随进度备份导出，不嵌入公开仓库。新浏览器未载入某组个人判定时，该条件显示“需核实”，不会擅自判为可佣兵推进。焰的区域探索、按键挑战、料理，结的饭团及七冰的专属阶段等已明确的补充规则包含在项目数据中。

这里录入的是查询工具的记录，不会修改游戏存档。实际游戏进度请自行核对。

## 项目结构

```text
index.html              页面入口
style.css               页面与圆环样式
app.js                  精英讨伐、筛选、关联角色
merc.js                 圆环编辑器、排序、分类
merc-engine.js          节点与佣兵团判断
player-store.js         进度保存与兼容导入
i18n.js                 语言切换与显示翻译
data.json / data.js     中文原始数据及离线加载版本
locales.json / locales.js 译文、名称来源及离线加载版本
assets/                 Wiki 异刃图片
tests/check.cjs         数据、规则、存档及语言回归检查
scripts/                单文件打包工具
docs/                   上传说明
```

`data.js` 和 `locales.js` 让 `file://` 方式无需请求 JSON。更新 JSON 后执行 `py scripts/sync_data.py` 同步对应 JS。无需修改浏览器安全设置。

## 开发检查

安装 Node.js 后，在项目根目录执行：

```powershell
node tests/check.cjs
```

测试覆盖当前下一节点规则、讨伐双向同步、形态互斥、个人规则备份及中英日名称/数字一致性。页面交互仍需通过浏览器检查。

如需生成便于转发的单文件网页，安装 Python 后运行：

```powershell
py scripts/build_standalone.py
```

输出位于 `dist/`，不需要将生成文件提交到 GitHub。

### 保存到电脑上的文件

页面上方的“本地进度文件”支持关联 JSON 自动保存（需要支持 File System Access 的 Chrome / Edge）。首次点击“新建并关联文件”，选择存放位置；之后圆环、讨伐勾选、个人规则及形态备份会自动写入。请等到“本地文件已保存”后关闭页面。下次打开网页，点击“打开已有进度文件”，确认载入同一文件，继续自动保存。

“断开关联”停止后续自动写入，浏览器缓存仍保留。文件若被其他窗口或程序修改，将停止写入并提示重新打开，避免覆盖新内容。不支持直接文件读写的浏览器仍可使用原有导出、导入功能。本地文件载入是完整替换；原“导入进度”仍是合并。
